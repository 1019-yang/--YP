# 千川信息流脚本

## 核心目标

把商品资料转成一条用户愿意停留、相信、看懂并采取行动的短视频。

默认链路：

> 目标人群痛点 → 结果或冲突钩子 → 真实证据 → 核心利益 → 使用场景 → 权益理由 → 明确行动

千川脚本不是卖点说明书。每条素材只解决一个核心购买障碍，并让主卖点能够被镜头、操作、对比或体验证明。

## 工作原则

1. 先识别用户为什么不买，再决定说什么。
2. 先展示结果或冲突，再补产品解释。
3. 一条视频只保留一个主卖点，最多增加两个辅助卖点。
4. 把产品语言翻译成用户利益，不堆参数和形容词。
5. 能实拍验证的卖点，必须尽量通过完整过程证明。
6. 权益只负责临门一脚，不能替代产品价值。
7. 不编造销量、排名、测试结果、用户反馈、资质或功效。
8. 平台规则、价格和机制可能变化；涉及实时信息时先核对最新资料。

## 第一步：建立最小产品事实集

从用户资料中提取：

| 字段 | 要回答的问题 |
| --- | --- |
| 产品 | 卖什么，属于什么品类 |
| 目标人群 | 谁最需要，谁最容易成交 |
| 核心场景 | 用户在什么时候产生需求 |
| 原始痛点 | 旧方案哪里麻烦、昂贵、低效或不确定 |
| 主卖点 | 只能选一个作为本条素材中心 |
| 辅助卖点 | 最多两个，用于增强可信度 |
| 证明方式 | 实拍、测试、对比、细节、资质或使用反馈 |
| 价格与权益 | 当前到手价、赠品、优惠、库存或时间限制 |
| 合规边界 | 禁用词、必要限定语、不可展示的操作 |
| 转化目标 | 点击商品、进入直播、加购、咨询或成交 |

若信息不足但不阻塞，可以做保守假设，并明确标记为“待品牌确认”。不要把假设写成事实。

## 第二步：判断内容任务

优先选择一个任务：

- `痛点拦截`：放大用户正在经历的麻烦。
- `效果验证`：用可见结果证明产品能力。
- `认知纠偏`：推翻用户对品类的常见误解。
- `场景种草`：让用户看见产品进入生活后的便利。
- `信任建立`：解释材质、技术、结构、标准或真实体验。
- `价格转化`：解释为什么此时买更划算。
- `直播引流`：制造“进直播间才有完整答案或权益”的理由。
- `人群筛选`：明确谁适合、谁不必买，提高流量精准度。

不要同时承担所有任务。

## 第三步：选择前3秒钩子

### 1. 结果前置

直接展示最强效果。

公式：

> `不用___，也能___。`

> `你看，___之后，结果居然___。`

适合：不粘、清洁、收纳、速度、妆效、质地、家电效果等视觉型卖点。

### 2. 痛点直击

指出一个具体且高频的麻烦。

公式：

> `每次___，最怕的不是___，而是___。`

> `如果你也总是___，先别急着___。`

### 3. 反常识提问

挑战品类惯性认知。

公式：

> `你以为___看的是___？真正该看的是___。`

> `为什么同样是___，有人用着省事，有人越用越麻烦？`

### 4. 对比冲突

用旧方案和新方案制造差异。

公式：

> `以前要___，现在只要___。`

> `同样做___，这两种结果差得有多大？`

### 5. 利益或稀缺

仅在权益确实有竞争力时使用。

公式：

> `这次最值得看的不是降价，而是___。`

> `如果你正准备买___，这个机制先别错过。`

避免单独使用空泛表达：`太香了`、`闭眼入`、`谁买谁赚`、`终于被我发现了`。

## 第四步：搭建脚本结构

### 15秒强转化版

| 时间 | 任务 | 内容 |
| --- | --- | --- |
| 0-3秒 | 钩子 | 最强结果、痛点或价格冲突 |
| 3-8秒 | 证明 | 一个完整操作或关键证据 |
| 8-12秒 | 利益 | 适合谁、解决什么 |
| 12-15秒 | 行动 | 权益 + 点击/进播指令 |

适合：单卖点、低决策门槛、成熟爆品、重定向素材。

### 25-35秒标准版

| 时间 | 任务 | 内容 |
| --- | --- | --- |
| 0-3秒 | 强钩子 | 结果、痛点、反常识或冲突 |
| 3-8秒 | 放大障碍 | 旧方法为什么麻烦或不确定 |
| 8-18秒 | 核心实证 | 完整演示主卖点 |
| 18-25秒 | 场景代入 | 谁适合、什么时候用 |
| 25-30秒 | 权益解释 | 为什么现在买或进直播 |
| 30-35秒 | 明确CTA | 点击、加购、进播或咨询 |

### 45-60秒高决策版

适合高客单、耐消品、技术型产品或多规格选择。

结构：

1. 前3秒给结果或最大冲突。
2. 说明用户原有方案的问题。
3. 解释主卖点背后的结构或技术。
4. 用完整实拍证明。
5. 补充适配人群、规格和场景。
6. 处理一个核心异议。
7. 说明权益与行动路径。

## 第五步：把卖点翻译成镜头

| 原始信息 | 用户利益 | 优先镜头 |
| --- | --- | --- |
| 材质升级 | 更安心、耐用或适合特定场景 | 材质标识、细节特写、资质 |
| 操作简化 | 单手完成、步骤更少 | 连续操作，不切断关键过程 |
| 多功能 | 少买、少洗、少占空间 | 一物多场景或同时完成 |
| 不粘/好清洁 | 成菜完整、清理省事 | 从下锅到翻面/清洁全过程 |
| 大容量 | 一次满足多人或批量需求 | 食材铺满、人数和份量对照 |
| 颜值设计 | 愿意摆出来、适配家居 | 环境搭配、使用中的产品 |
| 价格权益 | 降低尝试成本 | 原价/到手价/赠品清晰呈现 |
| 技术参数 | 结果更稳定 | 参数只做解释，效果必须可感知 |

## 第六步：口播写法

### 用户视角

用“我为什么换”“实际哪里省事”“谁会需要”表达。

模板：

> `以前我做___，最麻烦的是___。换成这个以后，最明显的不是___，而是___。你看___。如果你平时也___，它会比普通的___更省事。`

### 测试视角

模板：

> `卖点先不听我说，直接做一个___测试。从___到___全程不剪，你可以看到___。`

### 选购攻略视角

模板：

> `买___不要只看___。如果你是___，优先看___；如果你更在意___，再看___。`

### 直播引流视角

模板：

> `这场值得看的不是商品多，而是___。___人先看___，___人重点看___。具体规格和机制我会在直播间一次讲清楚。`

## 第七步：素材矩阵

同一产品至少拆成不同变量，不要只换开头：

| 变量 | 可测试方向 |
| --- | --- |
| 钩子 | 结果、痛点、反常识、价格、场景 |
| 人群 | 新手、家庭、专业用户、特定肤质/发质/需求 |
| 场景 | 早餐、通勤、旅行、家庭聚餐、换季、直播节点 |
| 证据 | 操作测试、对比、结构解释、用户反馈、资质 |
| 内容形态 | 第一视角、真人口播、开箱、测评、教程、混剪 |
| CTA | 商品点击、加购、直播预约、评论咨询 |

批量输出时，先定义测试矩阵，再生成脚本。每条至少改变“钩子 + 证明方式”中的一个核心变量。

## 耐消品与锅具适配

用于锅具、家电、家居等高演示价值品类时：

1. 优先用完整操作证明，避免只展示最终结果。
2. 拍摄食物时保证状态鲜活：沸腾、翻面、滑动、出汁、蒸汽。
3. 将技术参数翻译成“省哪一步、少洗什么、结果更稳在哪里”。
4. 高压锅等安全相关品类只使用品牌确认的安全表述。
5. 烹饪时长必须带清楚起算条件，例如“上汽后”。
6. 禁止展示品牌明确不允许的用法，例如未确认可用的钢丝球、铁铲。
7. 不粘测试尽量从下锅到出锅连续呈现，避免关键段落跳剪。

## 合规与证据

### 可以使用

- 用户提供并确认的材质、规格、功能和权益。
- 能通过镜头真实演示的操作与结果。
- 有明确来源的检测、认证、专利和销量信息。
- 明确标注为个人体验的主观感受。

### 必须谨慎

- `绝对不粘`、`零风险`、`百分百有效`等绝对化表达。
- `最安全`、`行业第一`、`全网最低`等比较或排名表达。
- 医疗、保健、疾病改善及永久性功效。
- 未提供依据的销量、复购率和用户证言。
- 虚构库存紧张、虚构倒计时或虚构原价。

如果证据不足，改为可验证的温和表达，并标注需品牌确认。

## 默认输出格式

### 1. 内容定位

- 产品：
- 目标人群：
- 核心痛点：
- 主卖点：
- 证明方式：
- 转化目标：

### 2. 脚本总表

| 时间 | 画面/动作 | 口播 | 花字 | 音效/剪辑 |
| --- | --- | --- | --- | --- |

### 3. 拍摄清单

- 必拍镜头
- 食材/道具/模特
- 景别与机位
- 关键完整过程
- 禁拍与注意事项

### 4. 备选钩子

至少输出3个不同逻辑的开场。

### 5. 标题与封面

输出3-5组“标题 + 封面压字”，突出痛点或结果。

### 6. 投放变量

说明本条素材在测试哪一项：钩子、人群、场景、证据或权益。

### 7. 合规自检

列出已确认事实、待确认表述和删除的风险词。

## 脚本诊断格式

用户提供现有脚本时，按以下顺序输出：

1. `核心问题`：指出最影响停留和转化的1-3点。
2. `保留内容`：哪些卖点或镜头值得保留。
3. `钩子重写`：给出3个方向。
4. `结构重排`：解释前后顺序如何调整。
5. `完整改稿`：输出可直接拍摄的脚本表。
6. `测试建议`：下一轮应改变什么变量。

## 最终质检

交付前逐项确认：

- 前3秒是否有明确结果、痛点、冲突或利益。
- 是否只围绕一个主卖点。
- 主卖点是否有镜头证据。
- 用户是否能在10秒内知道“这对我有什么用”。
- 是否明确适合人群和使用场景。
- 权益是否真实、清晰且不过度挤压产品价值。
- CTA是否与转化目标一致。
- 关键测试或操作是否完整。
- 是否删除无依据的绝对化、排名和功效表达。
- 是否标记品牌待确认项。
